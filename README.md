# Boulder Beta

A climbing tracker and social media platform to log and share climbs.

## Live

https://boulder-beta-1.onrender.com/

## Features

- Track progress in climbing projects
- Post your sends and get advice from other climbers on beta
- View analytics on climbing projects

## Installation

- Clone repository with `git clone`
- for each of the `server` and `src` directories:
  - navigate to directory
  - run `npm install` to install dependencies
  - run `npm run dev` to start the development server
